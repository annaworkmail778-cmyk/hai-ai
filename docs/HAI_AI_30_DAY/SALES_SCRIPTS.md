# Sales Scripts: Armenian, Russian, English, Creators

**Rules:**
- Personalise the **first line** with something real: their recent project, a service page, or a job post.
- One message → one question.
- Link 1 relevant demo, never 5.
- Send manually, one by one.
- Stop after "no" or 3 follow-ups.

**Placeholders:**
- `[Name]`, `[Agency]`, `[their service]`, `[demo link]`
- `[portfolio]`: riseup-group.com until the brand is decided
- `[price]`

### 3.6 Agency partnership proposal (send after the call)
```
White-Label Delivery Partnership — [Agency] × RISEUP
1. What we deliver under your brand: websites, dashboards/web apps, CRM integrations, n8n/GHL automations, AI assistants, AI video.
2. How we work: you own the client; we work from your brief; NDA; communication via your Slack or Telegram; 2 revision rounds.
3. Start: paid test task — [deliverable], $300, 3–5 days, prepaid.
4. Projects: fixed quote per brief; 50% upfront / 50% on handover (web apps 40/30/30).
5. Ongoing: capacity retainer — 30 h $1,200 / 60 h $2,200 per month, prepaid, 48-hour first response.
6. Payment: bank transfer (USD/EUR) to our Armenian business account or [Payoneer, if set up].
Next step: confirm the test task → invoice → kickoff call.
```

### 3.7 Discovery call script (15 min)
1. Their services, clients, team size.
2. Current delivery bottleneck.
3. Recent project they couldn't take or that ran late.
4. Tools: CMS, CRM, GHL, n8n.
5. Quality bar and process (briefs, design files).
6. Budget norms per project.
7. **Propose a test task now:** scope it live, then send the invoice today.

### 3.8 Upwork proposal templates

**Automation (n8n/Make/GoHighLevel):**
> Hi [Client], you need [restate the job in one line]. I've built similar flows: [1-line relevant example], with a 60-second demo here: [Loom]. Plan: (1) [step], (2) [step], (3) test + handover doc. Timeline [X] days. One question: [specific clarifying question]. Happy to start with the first milestone.

**Website / dashboard:**
> Hi [Client], for [project], I'd build it in [Next.js/WordPress] with [key feature]. Here's a similar dashboard I built: [Loom]. Milestones: (1) layout + data model, (2) features, (3) deploy + handover. [X] days total. Do you already have designs, or should I propose a layout first?

**Fix / rescue:**
> Hi [Client], from your description the issue is likely [hypothesis]. I'd start with a short audit milestone (I find the root cause and give a fix plan), then the fix milestone. I work daily with Claude Code + Supabase/Next.js. What's the repo/stack?

**After the first Upwork contract:**
- Over-deliver on communication.
- Ask for a review at delivery.
- Offer a small follow-up milestone ("monitoring + 2 improvements") within 48 hours.
