# Financial Target and Forecast

**Primary KPI:** **cash received by Day 30**.
**Tracked separately, never added to cash:**
- signed project value
- outstanding invoices
- pipeline value (sum of open proposals × probability)
- MRR (prepaid retainers + monthly fees active)

**Rate:** 1 USD ≈ 388 AMD [ASSUMPTION; use the bank rate on the day received].

**Conversion rates:** there is no reliable public benchmark for agency cold outreach. All rates below are **[ASSUMPTION]**. The only external anchor is a 2–4% Upwork reply rate for unbadged profiles (third-party estimate: https://aiproposer.com/learn/upwork-connects-economics-2026). **Replace every assumption with real tracker data at Gate D7.**

## Receiving payments as an Armenia-based business
Verify each method **with the provider before Day 1 outreach**.
