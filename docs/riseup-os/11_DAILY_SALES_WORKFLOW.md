# 11 — Daily Sales Workflow (two people)

Roles: **Founder** (sales + technical) and **Research & Ops** (the founder's wife). The hours each person has available have not been confirmed (doc 21). The plan below assumes about 6 h a day for the founder and about 4 h a day for Research & Ops.

## Daily rhythm

| Time | Founder | Research & Ops |
|---|---|---|
| 08:30 | Read the daily plan (skill output) | Generate the daily plan; check the bank for payments → `Payments` |
| 09:00–11:00 | **Calls block**: follow-ups, first calls to A-tier, meetings | Discovery: 15–20 new companies with sources |
| 11:00–12:00 | Review and approve drafts; send approved messages manually | Run `company-researcher` on new A/B companies; verify facts |
| 12:00–15:00 | Meetings or demos; proposals; build work for signed pilots | Score leads; prepare research briefs for tomorrow's calls |
| 15:00–16:00 | Second calls block | Prepare drafts (`outreach-drafter`) for the founder's review queue |
| 16:00–18:00 | Delivery and build work | CRM hygiene: dedupe, next_step dates, invoices |
| 18:30 | Dictate call notes → `deal-desk` | Apply the CRM diffs from `deal-desk` |
| 19:00 | Read the EOD report and pick tomorrow's top 3 | Generate the EOD report |

## Handoffs

```
Ops: company + sources ──▶ Ops: research brief (verified) ──▶ Ops: score + tier
   ──▶ Ops: draft prepared ──▶ FOUNDER: approve/edit ──▶ FOUNDER: send manually / call
   ──▶ FOUNDER: meeting + notes ──▶ deal-desk: summary + CRM diff ──▶ Ops: apply diff
   ──▶ FOUNDER: proposal (proposal-builder) ──▶ FOUNDER: send after self-review
   ──▶ signed ──▶ Ops: invoice + payment tracking ──▶ FOUNDER: delivery
```

## Weekly

- **Monday:** pipeline review. Compare expected and actual cash. Check segment and channel conversion. Kill stale deals.
- **Wednesday:** content. One LinkedIn or Instagram post from real work, with no invented results.
- **Friday:** retro. What to automate next? Only steps done 10+ times with a checklist.

## Activity targets (base scenario, doc 18)

| Per day (both people) | Target |
|---|---|
| New companies researched | 15–20 |
| First touches sent (manual, approved) | 5–10 |
| Follow-ups | 5–10 |
| Calls | 5–8 |
| Meetings (per week) | 4–5 |
| Proposals (per week) | 2–3 |
