# RISEUP Upwork / Contra Playbook

⚠ Before Day 1, confirm whether RISEUP Upwork/Contra accounts exist and in whose name (open question #6). One account per person, real identity, **no fake experience, portfolio or reviews**.

## Profile positioning
- **Headline:** "White-label web & automation builds — Next.js dashboards · n8n/Make · GoHighLevel · AI assistants"
- **Overview:**
  1. Who we are: a 2-person RISEUP team in Yerevan.
  2. What we build.
  3. How we work: fixed scope, a written plan within 24 h, 2 revision rounds.
  4. Demos: L2, L5, riseup-group.com.
- **Portfolio:** only our own demos, labelled "demo".
- **Rate:** $35/h at the start → $45/h after 3 five-star jobs.

## Categories to target
1. n8n / Make / Zapier automation
2. GoHighLevel setup
3. AI chatbot / WhatsApp / Telegram bot
4. Next.js / React dashboard, Supabase fixes
5. Landing pages (Next.js / Webflow)
6. CRM integrations (Kommo, HubSpot, Bitrix24)

## Jobs to avoid
- "Unpaid test", "free sample", "trial task" without payment.
- Budget < $100 fixed or < $15/h.
- Payment not verified, or 0 hires with 10+ jobs posted.
- Vague scope ("build an app like Uber") on a small budget.
- Requests to work or pay outside Upwork before a contract exists (against Upwork's terms).
- Academic or homework jobs; scraping that breaks site terms; "fake reviews / accounts".

## Serious-client checklist (≥ 5 of 7 to apply)
- [ ] Payment method verified
- [ ] ≥ $1k spent or ≥ 3 hires
- [ ] Hire rate ≥ 50%
- [ ] Average review given ≥ 4.5
- [ ] Clear scope, with a deliverable you can describe in 1 sentence
- [ ] Budget ≥ $200 fixed or ≥ $30/h
- [ ] Posted within the last 24 h, fewer than 20 proposals

## Proposal structure (≤ 150 words)
1. First line repeats their exact problem.
2. How we'd solve it, in 3 steps.
3. One relevant demo link (L2 for automation/AI, L5 for dashboards).
4. Price and timeline: fixed, or the first milestone.
5. One question that shows understanding.

Full templates: `docs/HAI_AI_30_DAY/SALES_SCRIPTS.md` §3.8.

## First pricing
| Job | First milestone |
|---|---|
| Small fix | $100–250 |
| Automation | $300–600 |
| Landing page | $400–600 |
| Dashboard | from $800, milestone 1 = 40% |

Below the WL rates only for the **first 3 jobs**, to build reviews. Never below $25/h effective.

## Demo use
- Record a 60-second Loom-style video answering their specific job, using an existing demo.
- Do not build custom work for free.

## Avoiding unpaid tests
"Happy to start with a small paid milestone ($100–200) so you can check quality. It's credited to the project."

## Daily target
- **B:** shortlist 6 jobs (10:30 and 16:00).
- **A:** sends 3–5 proposals (113 over 30 days in the plan).
- Log each proposal in Activities: Channel = Upwork/Contra, Type = Proposal.

- [ ] Decision maker
- [ ] Start date
