## Day 5 checkpoint (Fri 27 Nov)
**If no payment has arrived yet:** don't discount everything. Diagnose the bottleneck in the funnel:

| Symptom | Bottleneck | Fix (one only, for 3 days) |
|---|---|---|
| < 150 first contacts sent | Volume | B blocks 3 h/day for outreach only; A stops research |
| Reply rate < 3% | Message or targeting | Rewrite the first line; switch segment (e.g. CRM partners → marketing agencies); test the call channel |
| Replies but no calls | Call to action | Offer 2 concrete time slots; send the demo before asking for the call |
| Calls but no proposals | Qualification | Use the qualification checklist; propose a paid test on the call |
| Proposals but no payment | Offer or trust | Offer the paid test (WL-0) or a smaller phase 1; send the invoice the same day; follow up after 48 h |

A lower-priced pilot is allowed **only if margin stays ≥ 50%**: shrink the scope rather than cutting the price. Floors are in `OBJECTION_HANDLING.md`.
