# RISEUP Agency Outreach Playbook (white-label, primary channel)

**Positioning:** "RISEUP helps digital agencies deliver more client projects without hiring additional developers. We work behind the scenes under your brand."

## 1. ICP
| Criterion | Ideal |
|---|---|
| Type | Marketing/SMM, web/design/branding, SEO, CRM partners (Bitrix24/Kommo), automation/GHL agencies, small software studios (overflow) |
| Size | 3–30 people |
| Signal | Posts new client work; hiring a developer; sells websites/CRM without in-house developers; slow or outdated own site |
| Markets | Armenia (AMD), Russian-speaking (Georgia, Kazakhstan…; USD), EU/US (USD/EUR) |
| Decision maker | Founder, CEO, account/project director |

## 2. Qualification (ask on the first call; ≥ 3 "yes" = qualified)
1. Do you have client projects you can't deliver on time, or turn down?
2. Who builds websites/integrations today: an in-house team, freelancers, nobody?
3. Is a project waiting right now (or within 30 days)?
4. Do you decide on subcontractors yourself?
5. Typical project budget ≥ $500 / 200,000 ֏?
6. Will you pay a deposit or a paid test before we start?

## 3. Scoring
Use `LEAD_SCORING_MODEL.md`. Agency-specific hints:

| Factor | Score 5 when |
|---|---|
| Need | A project is waiting now |
| Repeat | 3+ projects per year |
| Deal size | ≥ WL-2 |

## 4. Outreach sequence
| Day | Channel | Action | Template |
|---|---|---|---|
| 0 | Email or LinkedIn/Instagram DM (+ WhatsApp in Armenia) | Personalised first contact + demo link | Scripts §1 |
| 0–2 | Phone (Armenia; others if a number is public) | Cold call | Scripts §3 |
| +2 | Same channel | F1: second demo | Scripts §4 |
| +4 | Other channel | F2: test offer | Scripts §4 |
| +7 | Same channel | F3: relevance question | Scripts §4 |
| +14 | Same channel | F4: close the loop → Follow-up Later | Scripts §4 |

Limits:
- **25 first contacts a day** at most, each with a personalised first line.
- **No bulk email tools** at launch. Send one by one from the RISEUP address.

## 5. Discovery call (15 min)
1. "What do you sell most? Who builds it?" (3 min)
2. "What projects did you turn down or delay in the last 3 months?" (3 min)
3. "How do you handle subcontractors: NDA, communication, invoicing?" (3 min)
4. Show L2 or L5 for 3 min, with the agency's client type in mind.
5. Next step: "Let's start with one paid test or the next real project. I'll send the proposal today."

## 6. Demo structure (10 min)
1. Problem in their words.
2. Demo flow: inquiry → automation → booking/CRM → report.
3. How white-label works: our work is unbranded, communication goes through the agency, and an NDA is available.
4. Price and timeline.
5. Ask: "Shall I send the test invoice?"

## 7. Proposal
- Template: `docs/RISEUP_BUSINESS_LAUNCH/AGENCY_PARTNERSHIP_PROPOSAL.md` + `MUTUAL_NDA_TEMPLATE.md` + `WHITE_LABEL_PARTNERSHIP_AGREEMENT.md`.
- Always include: scope, deliverables, timeline, price, payment structure (WL-0 100% upfront; WL-1–3 50/50; WL-4 40/30/30; WL-R prepaid monthly), 2 revision rounds, extra hours rate.

## 8. Closing
- Ask for the first payment directly (Scripts §12).
- If they hesitate: offer WL-0 or the agency's next small project as the test.
- **After the first delivery:** ask for (1) the next project, (2) a WL-R retainer, (3) one referral.

## 9. Objections
See `OBJECTION_HANDLING.md`. The ones agencies raise most: "we have a developer", "no case studies", "free test?".
